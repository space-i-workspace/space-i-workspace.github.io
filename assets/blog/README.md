# 블로그·게시판 글 사진 (assets/blog)

카페24 자사몰 **사업정보 게시판** 글에 쓰는 사진을 여기에 둔다.
카페24 게시판 저장 용량을 아끼려고, 글은 HTML 로 이 폴더의 사진 주소를 불러온다. (네이버 블로그·카페 글은 네이버에 바로 올리므로 여기 없음)

- `photos/` — 사진 원본 모음. 1000px·압축, **같은 사진은 한 번만** 저장(파일 이름 = 사진 지문). 여러 글이 같은 주소를 씀
- `cafe24/<게시일>_<글 이름>/README.md` — 글 제목·글 주소·그 글에 쓴 사진 목록(어느 photos 파일인지 + 설명)
- ⚠️ `photos/` 의 사진을 지우거나 이름을 바꾸면 게시판 글의 사진이 깨진다
- 관리: workspace/blogautomation_spacei (공간i 블로그 자동화) — Claude Code 가 올림
