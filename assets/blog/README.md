# 블로그·게시판 글 사진 (assets/blog)

카페24 자사몰 **사업정보 게시판** 글에 쓰는 사진을 여기에 둔다.
카페24 게시판 저장 용량을 아끼려고, 글은 HTML 로 이 폴더의 사진 주소를 불러온다.

- 주소 형식: `https://space-i-workspace.github.io/assets/blog/cafe24/<게시일>_<글 이름>/<번호>_<내용>.jpg`
- 폴더마다 README.md 에 **글 제목·글 주소**를 적어 두었다
- ⚠️ 이 폴더의 사진을 지우거나 이름을 바꾸면 게시판 글의 사진이 깨진다
